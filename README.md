# Сценарий 1: Заказ кастомной пиццы в офис к определенному времени

* **Актор:** Офисный сотрудник (зарегистрированный пользователь).
* **Цель:** Заказать две разные пиццы с индивидуальными топпингами в офис к началу обеденного перерыва.
* **Предусловия:** Пользователь авторизован, в профиле сохранен адрес офиса.

### Основной поток
1. Пользователь выбирает первую пиццу, добавляет к ней топпинги (дополнительная ветчина, без лука), выбирает размер **L**.
2. Добавляет пиццу в корзину.
3. Выбирает вторую пиццу из меню, меняет в ней один базовый ингредиент (если бизнес-правила позволяют), добавляет топпинг.
4. Переходит в корзину, проверяет состав.
5. Нажимает **«Оформить»**, выбирает сохраненный адрес офиса.
6. Выбирает тип **«В офис»**.
7. В поле времени выбирает завтрашнее число, **12:30**.
8. Выбирает оплату картой, вводит данные, подтверждает платеж.
9. Получает SMS с номером заказа.

### Альтернативные потоки
* **3а.** Бизнес-логика запрещает менять базовые ингредиенты, но разрешает только добавление. Система подсвечивает базовый ингредиент серым и показывает тултип.
